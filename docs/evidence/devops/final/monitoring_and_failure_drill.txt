## 3. Deliberate Failure & Recovery Drill (scripts/health-check.sh):
1. Normal State:
   - GET /api/v1/health/live -> 200 OK (Process Uptime: Active)
   - GET /api/v1/health/ready -> 200 OK (Database: Connected)
   - Gauge database_up: 1

2. Database Disconnection / Outage:
   - GET /api/v1/health/live -> 200 OK (Node process continues running)
   - GET /api/v1/health/ready -> 503 Service Unavailable (Database probe failed)
   - Gauge database_up: 0
   - Ingress controller halts routing checkout traffic; Grafana triggers threshold alert.

3. Recovery on Database Reconnect:
   - Database connection restored.
   - GET /api/v1/health/ready -> 200 OK (Automatic recovery)
   - Gauge database_up: 1
   - Order processing resumes immediately without application restart.
