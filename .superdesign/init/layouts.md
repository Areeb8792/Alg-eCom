# Superdesign Layouts Spec

## Layout Structures
1. **Public Storefront Layout (`StorefrontLayout`)**
   - Grain texture overlay (`grain-overlay`) across entire viewport
   - Fixed header (`header-transition`) with difference blend mode
   - Floating cart button (`cart-transition`)
   - Scrollable dynamic body (`main-content`)
   - Brutalist editorial footer (`main-footer`)
2. **Checkout & Order Layout (`MinimalLayout`)**
   - Clean high-contrast container with back navigation to catalogue
   - Focus on secure transactional form elements and verification feedback
3. **Admin Operations Layout (`AdminLayout`)**
   - Secured header with current actor identification and token status
   - Split dashboard for product catalog inventory adjustments, health signals, and audit events
