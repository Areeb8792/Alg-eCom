# Superdesign Extractable Components Spec

## Component Candidates
1. **`GrainOverlay`**: Viewport background texture SVG component.
2. **`Header`**: Fixed header with brand name, sub-brand metadata, navigation links, and difference blend mode.
3. **`FloatingCart`**: Top-right floating circular button with red badge counter.
4. **`ProductCard`**: Card with 3:4 aspect ratio, grayscale-to-color transition, title, price, category tag, and stock indicator.
5. **`StockBadge`**: Visual status indicating In Stock, Low Stock (< 5), or Sold Out.
6. **`AuditTable`**: Formatted table for audit logs showing timestamp, actor, entity, action, and payload diffs.
7. **`StatusIndicator`**: Live/Ready health ping pill for DevOps visibility.
8. **`Footer`**: Brutalist luxury footer with newsletter input and massive background brand watermark.
