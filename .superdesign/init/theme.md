# Superdesign Theme Tokens

## Colors
```css
:root {
  --concrete: #f2f2f2;
  --ink: #0a0a0a;
  --red: #dc2626;
  --white: #ffffff;
  --surface-dark: #121212;
  --border-light: rgba(0, 0, 0, 0.08);
  --border-dark: rgba(255, 255, 255, 0.12);
}
```

## Typography
```css
--font-heading: 'Anton', sans-serif;
--font-sans: 'Space Grotesk', sans-serif;
```

## Shadows & Elevations
```css
--shadow-sharp: 10px 10px 0px rgba(0, 0, 0, 0.1);
--shadow-sharp-dark: 8px 8px 0px rgba(0, 0, 0, 0.4);
```

## Transitions
```css
--transition-grayscale: filter 700ms ease, transform 700ms ease;
--transition-link: all 200ms ease-in-out;
```
